# v0.1.2 implementation verification

Date: 2026-08-14
Scope: Android TLS full-duplex reconnect, launcher icons, system capture policy, release version/docs.

Two independent reviews ran in parallel from different model families: Codex-large and Claude-large. Initial findings were preserved and resolved before a second independent security review.

## Initial findings and dispositions

| Severity | Finding | Disposition |
|---|---|---|
| P0 | Post-handshake delegated tasks could run under the engine monitor. | Fixed: `NEED_TASK` after handshake fails closed; regression proves the task is not run. Initial handshake task handling is unchanged. |
| P0 | Unwrap-side `NEED_WRAP` could block the read pump on transport output. | Fixed: ordered encrypted records enter a bounded 8 MiB-equivalent egress actor; overflow fails closed. Regression proves a second inbound record is delivered while output is blocked. |
| P1 | Close could wait behind blocked egress output. | Fixed: TLS close no longer emits while closing; WebSocket close no longer waits for its write mutex. Regression proves bounded close. |
| P1 | Mutable `SSLEngine` operations/export could overlap. | Fixed: one lock covers wrap, unwrap, session reads, export, and engine close. Deterministic three-thread regression proves no overlap. |
| P1 | Screenshot test exercised only unpaired launch. | Fixed: `ScreenCapturePolicy` exhaustively clears `FLAG_SECURE`; instrumentation pre-sets the flag and verifies a `Trusted` state clears it. |
| P1 | Capture-policy reversal lacked an ADR and described Recents as user initiated. | Fixed: ADR-0021 records user screenshots and automatic OS Recents previews as intentional disclosure surfaces. |
| P1 | Physical evidence and release-version docs contradicted canonical state. | Fixed: docs distinguish verified Pixel 8 Pro + Bitwarden registration/certificate issuance from pending auth-to-sync and remaining physical gates; release candidate is consistently 0.1.2/code 3. |
| P1 | Legacy round launcher fallback lacked transparency. | Fixed: all density-specific round PNGs use a circular alpha mask; adaptive icons remain unchanged. |

## Final review

Both independent re-reviewers reported **no P0, P1, or P2 findings**. Security-sensitive TLS and capture fixes were explicitly re-reviewed.
